# Scooter API Tests

Проект с API-автотестами для сервиса заказа самокатов.

Цель проекта — проверить backend-сценарии сервиса через REST API: создание курьера, авторизацию, создание заказа, получение списка заказов и обработку ошибок.

## Что тестируется

- создание курьера
- создание курьера с некорректными данными
- создание курьера с уже существующими данными
- авторизация курьера
- авторизация с неверными данными
- создание заказа
- получение списка заказов
- обработка ошибок backend-сервисом

## Технологии

- Python
- Pytest
- Requests
- REST API
- JSON
- Git

## Что проверяют тесты

- HTTP-статус-коды
- структуру JSON-ответов
- позитивные сценарии
- негативные сценарии
- обязательные поля в запросах
- сообщения об ошибках
- обработку некорректных данных

Как запустить проект

Клонировать репозиторий:
git clone https://github.com/PavelKuznetsov11/scooter-api-tests.git

Перейти в папку проекта:
cd scooter-api-tests

Создать и активировать виртуальное окружение:
python -m venv venv

Для Windows:
venv\Scripts\activate

Для macOS / Linux:
source venv/bin/activate

Установить зависимости:
pip install -r requirements.txt

Запустить тесты:
pytest -v

Примеры проверок:
успешное создание курьера
ошибка при создании курьера без обязательного поля
ошибка при создании дубликата курьера
успешная авторизация курьера
ошибка при авторизации с неверным логином или паролем
успешное создание заказа
получение списка заказов

Результат:
В проекте реализованы API-автотесты для проверки основных backend-сценариев сервиса заказов.
Тесты проверяют статус-коды, JSON-ответы, позитивные и негативные сценарии.
